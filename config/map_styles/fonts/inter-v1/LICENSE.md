This repository does not commit Inter source font binaries for this map glyph set. Do not add `.ttf`, `.otf`, `.woff`, or `.woff2` files under this tree. Future font upgrades must generate and publish a new versioned glyph tree such as `fonts/inter-v2` rather than mutating `inter-v1`.
